# Simple Imputation Methods

## Statistical Measures
- **Mean Imputation** - Replace with average of available values
- **Median Imputation** - Replace with middle value (robust to outliers)
- **Mode Imputation** - Replace with most frequent value (categorical data)

## Forward/Backward Fill
- **Forward Fill** - Use the last known value
- **Backward Fill** - Use the next known value
- Common in time-series data
